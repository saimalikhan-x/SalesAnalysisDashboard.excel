# 📊 Sales Analysis Dashboard — Excel

A professional **Sales Analysis Dashboard built in Microsoft Excel**, transforming raw sales data into clear business insights through **PivotTables, KPIs, formulas, and data visualization**.

* Discount Analysis
* Sales by City & Region
* Category & Payment Mode Analysis
* Interactive PivotTable-based reporting

**Microsoft Excel • Data Cleaning • PivotTables • Data Analysis • Data Visualization**

Built as an **entry-level Data Analytics portfolio project** to demonstrate practical Excel skills and business-focused data analysis.
